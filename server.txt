## 3. Upload Backend (Spring Boot JAR) Build

**From local machine (SCP):**

```
scp -i property-pem.pem "C:\StartupWorkspace\construction management system\backend\madhavconstruction\target\app.jar" ubuntu@13.205.84.104:/home/ubuntu/
```

**On server, restart backend service:**

```
sudo systemctl stop madhavbackend
sudo systemctl start madhavbackend
sudo systemctl status madhavbackend
```

**Build backend locally without running tests:**

```
mvn clean package -DskipTests
```

## 4. Nginx Management

**Sites Available / Enabled:**

```
cd /etc/nginx/sites-available/
sudo nano madhavfrontend
sudo ln -s /etc/nginx/sites-available/madhavfrontend /etc/nginx/sites-enabled/
sudo systemctl reload nginx
sudo systemctl restart nginx
sudo systemctl status nginx
```

**Default frontend config (`madhavfrontend`):**

```
server {
    listen 80;
    server_name _;

    root /home/ubuntu/frontend;
    index index.html;

    location / {
        try_files $uri /index.html;
    }

    location /v2/api/ {
        proxy_pass http://127.0.0.1:8081/v2/api/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_cookie_path / "/; HttpOnly; SameSite=lax";
    }
}
```

## 7. Systemd Service File (Backend)

`/etc/systemd/system/madhavbackend.service`

```
[Unit]
Description=Madhav Construction Backend
After=network.target

[Service]
User=ubuntu
WorkingDirectory=/home/ubuntu
ExecStart=/usr/bin/java -jar /home/ubuntu/app.jar
Environment="MONGODB_USERNAME=triangledeal"
Environment="MONGODB_PASSWORD=DMJvd7T20WwZGr9P"
Environment="MONGODB_DB=madhavconstruction"
SuccessExitStatus=143
Restart=always
RestartSec=5
StandardOutput=file:/home/ubuntu/app.log
StandardError=file:/home/ubuntu/app.log

[Install]
WantedBy=multi-user.target
```

**Reload systemd after editing service file:**

```
sudo systemctl daemon-reload
sudo systemctl restart madhavbackend
sudo systemctl enable madhavbackend

```
